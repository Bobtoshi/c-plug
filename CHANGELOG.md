# Changelog

## 0.3.0 — 2026-08-21

- Rename the product and repository to C-Plug.
- Add a universal server-side AI provider layer for OpenAI Responses, OpenAI-compatible chat APIs, Anthropic Messages, Google Gemini, and loopback local models.
- Allow any uppercase API-key environment variable name without exposing its value to the browser, ledger, message channels, errors, or telemetry.
- Rename commands, environment settings, data files, and the macOS LaunchAgent to the `CPLUG`/`com.cplug.agent` namespace.

## 0.2.0 — 2026-08-21

- Publish the local-first personal operator as community source.
- Add an official WhatsApp Cloud API command channel with signed webhooks, exact owner allowlisting, deduplication, and shared approval codes.
- Retain paired iMessage, local web/voice control, Calendar, Mail, Apple Shortcuts, and read-only SSH status connectors.
- Harden local mutation routes, environment-file permissions, HTTP timeouts, CSP, CI action pinning, and release checks.
